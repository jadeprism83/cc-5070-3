# 高速载具跟随构图镜头

通过**屏幕死区 + 速度前瞻 + 受限旋转**实现的高速载具跟随镜头模块，直接控制三维相机位姿（位置与偏航/俯仰），而非移动界面标记。

## 图形入口（载具镜头演示）

```bash
npm run demo        # 启动静态服务器
# 打开 http://localhost:8123/demo/
```

演示场景内容：

- **可驾驶载具**：`W/S` 油门/刹车，`A/D` 转向，`R` 重置回自由驾驶；方向键同效。
  按住 `S` 停稳后再继续按即可倒车。
- **前视距离滑杆**（4–30 m）与死区宽/高滑杆，实时作用于镜头实现。
- **场景按钮**：`自由驾驶` `虚构赛道驾驶` `驾驶镜头脚本` `加速测试` `连续弯道` `侧滑测试`。
  按钮直接驱动 `src/` 下同一套 FollowCamera 实现实时仿真，追随画面与构图偏差全部来自当场计算。
- **赛道自动驾驶**（复选框）：在虚构赛道上由路径控制器驾驶，可观察高速过弯；随时可手动接管。
- **载具镜头资源区**：载入 `samples/driving-line/shot.json`，展示入库样片缩略图与原始记录核验结果；
  `载入样例参数` 把样例镜头参数应用到驾驶镜头脚本，`在本场景回放样例` 按入库原始记录逐帧驱动本场景相机。
- **结果区**：实时帧（车速、构图误差 ex/ey/|e|、偏航/俯仰角速度、留白、死区状态、构图目标、
  实际前视距离、主体投影偏差、脚本阶段）与本次运行汇总（构图误差、主体投影、运动成本分列），
  另有俯视轨迹记录图（白=载具轨迹，青=相机轨迹，红/紫=构图目标点）。
- **运行状态与异常区**：分别标出 `运行状态`、`追随画面`（死区内/纠偏中）、`构图偏差`（是否超出死区）、
  `样例核验` 与 `样例重建偏差`，并把主体在相机背后、角速度超限、构图越界、样例不一致等列为异常。
- 主视图即跟随相机的真实三维视图；HUD 叠加死区框（绿=目标在区内，红=区外纠偏中）、
  期望锚点十字、构图目标点与倒行时的主体投影圈（绿）。

## 驾驶镜头样片（入库资源）

`samples/driving-line/` 是可编辑、可核验的驾驶镜头样例：

| 文件 | 内容 |
| --- | --- |
| `shot.json` | 镜头配置（`cameraParams`）、剧本阶段、样片清单、指标、原始记录哈希 |
| `raw.json` | 逐帧原始记录：控制量、载具状态、相机位姿、前瞻点/主体点、投影偏差、前视距离 |
| `replayDrivingShot.js` | 重建脚本：只依赖 `shot.json` + `raw.json` + 仓库 `src/`，逐帧复算相机位姿 |
| `shot_0*.png` | 真实相机位姿渲染的样片（含一张倒行主体构图），非固定数据 |
| `shot_map.png` | 俯视轨迹与构图目标点记录 |

```bash
npm run shot:build     # 在净目录 samples/driving-line/ 重跑并生成全部资源
npm run shot:check     # 只读核验：样片存在、哈希、前瞻距离随速度伸展、主体位置、重建一致
npm run shot:replay    # 直接重放并比对相机位姿
```

净目录约束：`shot:build` 拒绝写入非空目录，避免用历史样片冒充新结果。核验失败时不会写出任何样片。
场景内容为虚构环线：长直道全油门加速（峰值约 27 m/s）、高速左弯、出弯加速、急刹、倒车（约 -5 m/s）后停稳。

## 命令行（仅辅助）

```bash
node tools/cli.js accel|curve|sideslip|all [--look=12] [--dt=0.0167] [--save]
```

打印各场景的构图误差 / 镜头运动成本 / 前方留白指标；`--save` 把轨迹记录（JSON）、
真实相机视图（PNG，软件渲染器与演示共用同一相机位姿数学）与俯视轨迹图写入 `results/`。
`npm run record` 等价于 `node tools/cli.js all --save`。

## 测试

```bash
npm test
```

覆盖：加速（前视距离随速度伸展、角速度限幅、前方留白、非固定距离尾随）、连续弯道
（弧线前瞻 vs 直线外推对照真实未来位置）、侧滑（前瞻跟随速度方向、无振荡）、
帧率无关性（同一载具轨迹在 30/60/120 fps 与抖动步长下偏航轨迹偏差 < 1°）、
死区投影语义（距离不变性、长宽比不变性、区内不旋转）、
驾驶镜头（虚构赛道高速弯 + 急停 + 倒行：倒行切主体构图、主体始终在相机前方、无镜头翻转、
前瞻距离按原始记录弦长随速度伸展）、旧样例回归（`results/*.json` 逐帧位姿一致）。

## 设计要点

- **死区定义在投影空间**：坐标按垂直半视场归一化，x 轴经长宽比修正（`ax = nx·aspect`），
  因此死区含义与画面长宽比、目标距离均无关（测试中有专门断言）。目标在死区内时相机
  完全不旋转；越界时只纠超出部分，目标回到死区边缘而非中心。
- **速度前瞻沿路径而非直线**：前瞻点由当前速率与横摆角速度积分出的**弧线**预测
  （`∫ rotY(ωt)·v dt` 闭式解），转弯时视线贴着真实路径走；测试证明圆周段弧线前瞻
  距真实未来位置 ~0.3 m，而"速度×常数"直线外推偏离 ~9.7 m（会被抛进弯道外侧障碍区）。
  横向偏移另有 `maxLateral` 限幅兜底。侧滑时前瞻基于速度方向（漂移感知），而非航向。
- **倒行切换到主体构图**：倒车时速度方向的前瞻点必然落到相机背后（相机始终在车头一侧），
  继续追前瞻点会导致镜头原地翻转 180°。因此纵向速度降到 `reverseEnterLong` 以下后，
  构图目标改为载具主体位置；`reverseExitLong` 滞回，停车换挡抖动不改变构图目标。
  逐帧诊断保留 `leadBehindCamera`（原始前瞻点相对相机前向的点乘）作为切换依据的证据。
- **受限旋转**：偏航/俯仰角速度硬上限（默认 150°/s、90°/s），俯仰角范围受限；
  期望姿态由投影残差迭代求解，精确收敛到死区边缘。
- **帧率无关**：所有积分采用显式时间策略——精确阻尼 `1-exp(-k·dt)` 加角速度·dt 限幅，
  不使用任何按帧固定的插值系数；30/60/120 fps 与随机抖动步长下结果一致。
- **构图误差与镜头运动成本分别度量**：前者是目标在投影空间相对期望锚点的偏差，
  后者是角行程/角速度，两者在测试、命令行与演示结果区中始终分列。主体投影偏差另列一项，
  作为倒行构图的核验口径。
- 视场角固定 60°，不依赖扩大视场掩盖前瞻失效；相机位置为弹性跟随锚点
  （距离随速度变化），非刚性固定距离尾随。

## 模块结构

```
src/followCamera.js   镜头核心：弧线前瞻、投影空间死区、受限旋转、倒行主体构图（浏览器/Node 共用）
src/vehicle.js        载具运动模型（油门/转向/抓地衰减，可侧滑）
src/trajectories.js   既有场景定义与仿真驱动（加速/连续弯道/侧滑，演示与测试共用）
src/track.js          虚构赛道几何：直线/圆弧段、弧长采样、最近点投影、路缘障碍
src/drivingShot.js    驾驶镜头剧本与路径驾驶控制器（加速/弯道/急停/倒车），逐步执行器
src/metrics.js        构图误差 / 主体投影 / 运动成本 / 前方留白 汇总
src/math3d.js         向量与矩阵（列主序，WebGL 约定）
src/scene.js          路侧障碍/场景道具生成
src/softrender.js     软件光栅化器（无头渲染真实相机视图 PNG）
demo/                 图形入口：WebGL 演示场景（index.html）
samples/driving-line/ 入库驾驶镜头样例（shot.json / raw.json / 重建脚本 / 样片）
tests/run.js          验证套件（npm test）
tools/buildDrivingShot.js  净目录生成驾驶镜头样例（样片 + 原始记录 + 重建脚本）
tools/checkDrivingShot.js  只读核验入库样例（哈希 / 前瞻距离 / 主体位置 / 重建）
tools/cli.js          辅助命令行（既有三个场景）
tools/serve.js        演示静态服务器
```

## 主要参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `lookAheadDist` | 12 m | 前视距离（演示滑杆可调 4–30 m），另随速度附加 `speedLeadTime`×车速 |
| `deadZone` | 0.22 / 0.16 | 死区宽/高，投影空间（垂直半视场单位，x 经长宽比修正） |
| `anchor` | (0, 0.1) | 期望构图锚点，同在投影空间 |
| `maxYawRateDeg` | 150°/s | 偏航角速度上限（俯仰 90°/s） |
| `maxLateral` | 10 m | 前瞻横向偏移限幅（相对航向） |
| `fovYDeg` | 60° | 垂直视场角，常规取值 |
| `reverseEnterLong` | -0.25 m/s | 纵向速度低于此值切入倒行主体构图 |
| `reverseExitLong` | 0.5 m/s | 纵向速度高于此值退出倒行构图 |
| `subjectAimHeight` | 1.0 m | 倒行时瞄准的主体离地高度 |
